# プライバシーポリシー

この文書は、本アプリプライバシーポリシーを定めるものです。  

## 1. 取得する情報

### 1-1. 認証とアカウント管理に必要な情報

- Google / Apple / LINE ログインを利用した場合:
  - 各認証事業者から受け取る識別子、認証用トークン
  - メールアドレスや表示名など、認証事業者から提供された情報
- メール認証を利用した場合:
  - メールアドレス
  - 認証コードの送信と確認に必要な情報
- セッション管理のための情報:
  - アクセストークン
  - リフレッシュトークン
  - ログイン中の端末情報

### 1-2. ユーザーが設定するプロフィール情報

- 表示名
- アカウント名
- 自己紹介
- Webサイト URL
- SNS リンク
- プロフィールアイコン画像

ユーザーが設定したプロフィール情報は、アプリ内や公開プロフィールページで表示される場合があります。

### 1-3. API 利用時に自動送信される情報

- 利用プラットフォーム
- 端末名または機種名
- アプリバージョン
- アクセスログ、エラーログ、セキュリティログ

### 1-4. 端末内だけに保存する情報

- ログイン状態を維持するための認証トークン
- テーマ設定などの表示設定
- Google ログイン復帰待ち状態など、認証処理を安定させるための一時情報

### 1-5. 権限を使う情報

- カメラ / 写真ライブラリ:
  - プロフィールアイコン画像の撮影または選択時にのみ利用します。
- 位置情報:
  - 対応機能で必要になった場合にのみ利用します。
  - 取得する場合も、市区町村レベルの大まかな情報に限定します。
  - 緯度経度の恒久保存は行いません。

## 2. 利用目的

取得した情報は、次の目的で利用します。

- ログイン、本人確認、アカウント連携、セッション管理のため
- プロフィール情報の表示、公開プロフィール URL の共有、アカウント設定のため
- 端末ごとのログイン状況表示やセキュリティ対策のため
- 不正利用防止、障害調査、運用保守のため
- お問い合わせ対応、法令に基づく対応のため
- カメラ、写真ライブラリ、位置情報を使う機能を提供するため

## 3. 外部サービスと第三者提供

- 本アプリは、ログイン機能のために Google、Apple、LINE の認証基盤を利用します。
- 本アプリは、アカウント管理とプロフィール機能のために当社または当社が管理する API / サーバー基盤を利用します。
- ユーザーが公開設定として登録したプロフィール情報は、他の利用者や公開プロフィールページから閲覧できる場合があります。
- 法令に基づく場合を除き、取得した個人情報を本人の同意なく販売したり、広告目的で第三者へ提供したりしません。
- 本アプリには、広告配信 SDK や行動追跡を主目的とする解析ツールを組み込んでいません。

## 4. 端末内保存とアカウント無効化

- 認証トークンや表示設定は、ログイン維持やアプリ利用のために端末内へ保存されます。
- アプリ内の「アカウントの無効化」を実行すると、現在のログイン状態は終了し、この端末に保存された認証情報も削除されます。
- 現在の設計では、同じ認証方法で再度ログインすると、同じアカウントを再開できる場合があります。
- 開示、訂正、利用停止、削除等の請求を希望する場合は、下記の窓口からご連絡ください。

## 5. 改定

本ポリシーは、法令やサービス内容の変更に応じて改定することがあります。重要な変更がある場合は、アプリ内または公開ページでお知らせします。
